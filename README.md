# 米游活动到期提醒

原神、崩坏：星穹铁道、绝区零 **国服**活动与周期奖励到期提醒，提供中文日报和 JSON 数据源。
作者本人用于Astrbot拉取并推送，若这份日报能帮助你，欢迎使用。

> 非官方社区项目，与米哈游及其关联公司无隶属或背书关系。游戏名称和商标归各自权利人所有。时间与奖励规则以游戏内信息和官方公告为准。

## 推送时检查内容

- **3 天内结束的活动**：距离实际截止大于 0 且不超过 72 小时；符合条件时每天重复提醒。这是日报核心内容。
- **7 天后结束的活动**：截止日期换算到日本时间后，恰好是核查当天日期加 7 天；不是精确相差 168 小时。本条目的设计初衷是一定程度上提前提醒用户安排日程。
- 覆盖限时活动、周期挑战和永久玩法中的限时奖励；排除普通每日任务和体力刷新
- 区分玩法结束、领奖截止和新一期刷新；未确认的候选保留核验说明

包括但不限于深境螺旋、幻想真境剧诗、幽境危战、式舆防卫战、危局强袭战、混沌回忆、虚构叙事、末日幻影。名称、开放状态与周期按当前公告核对。

## 时间与更新

计划每天 **08:00 Asia/Tokyo（日本时间）** 开始核查，完成后更新，若要稳定拉取，考虑时间定位北京时间8点即可。日报中的截止时间明确按 **北京时间 UTC+8** 标注，日本时间比北京快 1 小时。

以 `report_date` 和 `generated_at` 判断数据新鲜度。正文的“剩余时间”是核查时快照，不会随读取自动递减。网络、资料或发布异常可能导致更新延迟，请勿把旧日报当作最新结论。

## 数据如何核对

先检查 [Event Clock](https://stereotypicalcat.github.io/gacha-event-tracker/) 及各游戏数据源的刷新状态，再分别检索国服官方公告、周期排期，用维护中的攻略或 Wiki 交叉核对。Event Clock 没有收录不代表活动不存在。国际服专属社区活动不作为国服活动；推算时间和待核实事项会明确标记。

## 阅读与订阅

直接查看 [最新日报 JSON](./feed.json)。机器读取可使用 GitHub Contents API：

```text
GET https://api.github.com/repos/AmahaShio/mihoyo-event-deadlines/contents/feed.json
Accept: application/vnd.github.raw+json
```

公开读取不需要访问令牌。建议每 5–10 分钟检查一次，并遵循 GitHub 返回的限流信息。首次接入应先验证所用客户端能读取，不能仅凭浏览器可打开就认定程序兼容。

### 响应格式

```json
{
  "status": "ready",
  "report_id": "games-cn-YYYY-MM-DD-v1",
  "report_date": "YYYY-MM-DD",
  "timezone": "Asia/Tokyo",
  "generated_at": "带时区的 ISO 8601 时间",
  "body": "完整中文日报，含来源链接"
}
```

- `ready`：可读取 `body`；保留链接和核验说明
- `empty` / `no_qualifying_report`：完整检查后没有符合提醒条件的内容，不发送空日报
- 查询失败不能表示为“没有活动”；核验限制应保留在报告中
- 同一个 `report_id` 的日期和正文不可变；修订使用新 ID
- 当前接口只提供单个最新报告，不是历史报告数组

转发程序应校验报告日期、生成时间和状态，按目标与报告 ID 去重；同日同正文也可去重。发送超时可能已送达，不应无限重试。QQ、邮件等分发都是可选接入方式，本仓库本身不会自动向任何人发消息。

## 隐私与边界

仓库只发布游戏公开资讯，不包含玩家账号、QQ 号、SID、机器人配置、密钥或私人聊天。请勿在 Issue 或提交中上传此类信息。

公开提交历史会保留旧版报告。此项目不保证无遗漏，也不代替游戏内确认；尚未声明全面的客户端兼容性或全天候可用性。
